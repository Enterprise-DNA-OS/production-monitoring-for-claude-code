Run `npm run production -- changeovers --json`.

Show machine, from, to, times, average, best and worst. The gap between the average and the best is the prize: say it in minutes per changeover and minutes a month (gap times the number of changeovers, scaled to four weeks).

If an action was closed on a changeover, check `/insights` question 8 to see whether it worked.
